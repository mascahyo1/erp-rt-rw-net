## Lessons Learned

1. **Generator script > manual edit** untuk refactor 86 file. Dry-run dulu sebelum apply. Pattern-based regex harus handle 3 variant (`const BASE` vs `this.baseUrl` vs inline).
2. **Windows path portability:** forward-slash `/c/laragon/...` (Git Bash) vs backslash `C:\laragon\...` (Node) vs double-escaped `C:\\\\laragon\\\\...` (di dalam PHP single-quote string) — semua harus di-convert ke `path.resolve(__dirname, ...)` based.
3. **DEEP test pattern:** assert di level error message spesifik ("tidak terdaftar di perusahaan", "dinonaktifkan"), bukan cuma "form submit success/fail". Soft assert `safeTest(name, fn)` biar lanjut meski 1 case fail (summary di akhir, bukan stop di tengah).
4. **Helper `testUsers.cjs`:** PHP inline script > `factory()` — bypass UUID v7 + bcrypt + tenant scope yang rewel, langsung dapat user real di DB.
5. **Native Vue setter pattern:** untuk input yang `v-model` ada computed/modifier, `page.fill()` kadang tidak trigger reactivity. Solusi: `nativeSetter.call(input, value)` + dispatch `input` event.
