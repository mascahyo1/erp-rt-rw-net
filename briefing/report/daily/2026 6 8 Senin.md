## Catatan Tambahan

**Lesson learned (konsolidasi):**
1. **Test methodology** — `fill()` set value via JS, `type()` simulate real keystrokes. Untuk search/dropdown component, WAJIB test dengan `type()` (atau manual test) supaya keydown event bugs ke-detect.
2. **Audit existing tests** — saat refactor, cek selector stability. Selector `'.fixed.z-\\[60\\]'` fragile ke Tailwind class change. Selector `data-testid` stable lintas refactor.
3. **Per-key preventDefault** — saat handler ke-trigger untuk banyak keys, JANGAN panggil `preventDefault()` blanket. Scope per-key.
