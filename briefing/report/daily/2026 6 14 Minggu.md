## Catatan Tambahan

**Lesson learned (konsolidasi):**
1. **`<script setup>` functions NOT global** — Vue 3 SFC `<script setup>` tidak auto-expose ke `window`. Untuk callback yang dipanggil external script (Turnstile, Midtrans snap, payment gateway), HARUS manual `window.onXxx = ...` di `onMounted` + cleanup `delete window.onXxx` di `onBeforeUnmount`.
2. **Cloudflare testing keys pattern** — pakai `1x0000...` untuk sitekey+secret selalu pass, `2x0000...` selalu fail. Memudahkan E2E test tanpa setup real Cloudflare account.
3. **Throttle counter shared per IP** — Laravel `throttle:5,1` middleware pakai `sha1(domain+IP)` cache key. SEMUA routes yang pakai middleware ini share counter. Untuk test, flush `storage/framework/cache/data/*` (selain `cache:clear`) untuk benar-benar reset counter.
4. **VPN/HTTPS limitation** — Cloudflare Tunnel + Vite HMR tidak kompatibel karena Chrome Private Network Access (PNA) policy block HTTPS→HTTP loopback. Untuk dev lewat tunnel: pakai `npm run build` (built assets) bukan `npm run dev` (HMR).
